# what2eat 菜谱库

这是 what2eat 的 Obsidian 知识库，也是 MCP 默认读取的知识根目录。

## 入口

- [[维护说明|知识库维护说明]]
- [[ingredients/ingredients|标准食材目录]]
- `recipes/`：已发布、草稿与归档菜谱；版本文件使用 `recipes/<recipe_id>/<菜名>-v<version>.md`——文件夹名是稳定的 `recipe_id`，文件名前缀是发布时刻的中文菜名，图谱/快速切换器里不会都显示成同名 "v1"。
- `substitutions/`：食材替换或省略规则；用于“买不到”“不喜欢”或预算调整。
- `relations/`：菜谱之间的替代、搭配、变体和剩余食材关系。
- `prices/`：维护者基准价；实时/省级价格仍由 MCP 数据源提供。
