# what2eat 菜谱库

这是 what2eat 的 Obsidian 知识库，也是 MCP 默认读取的知识根目录。

## 入口

- [[维护说明|知识库维护说明]]（人看）/ `AGENTS.md`（AI 协作助手看，Obsidian 里嵌入的编码助手会自动读取）
- [[ingredients/ingredients|标准食材目录]]
- `recipes/`：已发布、草稿与归档菜谱；版本文件使用 `recipes/<recipe_id>/<菜名>-v<version>.md`——文件夹名是稳定的 `recipe_id`，文件名前缀是发布时刻的中文菜名，图谱/快速切换器里不会都显示成同名 "v1"。每篇菜谱可以标一个 `dish_role`（荤/素/汤/主食/凉菜），配餐和整菜替代靠它实时检索匹配，不需要手动建关系。
- `substitutions/`：食材替换规则，只用于真正"换成另一种食材"的场景；单纯"能不能省略"直接写在菜谱自己的 `ingredients[].optional` + `notes` 里。
- `prices/`：维护者基准价；实时/省级价格仍由 MCP 数据源提供。

> Obsidian 的双向链接用于人工浏览；MCP 读取 YAML frontmatter 中的稳定 ID 和结构化字段。不要只写双链而省略结构化字段。
